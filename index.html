Definizioni degli item

Gli item sono scritti nel linguaggio "Rendi". Ogni modifica viene controllata mentre scrivi: se è corretta, l'app si aggiorna subito e la salva su questo telefono.

Come si scrive un item 
foglio "Nome del foglio" "Codice foglio"

item "Titolo" Codice_Item
  nota "Testo di aiuto"
  euro x "Etichetta"          # campo in euro
  numero n "Etichetta"        # campo numerico
  scelta s "Etichetta" ["A", "B"]
  tmp = x * 7%                # valore intermedio
  risultato euro r "Etichetta" = min(tmp, 100)
  risultato perc p "Etichetta" = x / n * 100
  verifica "ok" | "errore" : r <= x
  avviso "se vero" | "se falso" : s == "A"

Funzioni: se(cond, a, b), min, max, abs, arrotonda(x, cifre)
Condizioni: == != < <= > >= and or not
